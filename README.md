# Welcome to radio-astronomy-by-notebooks

To set everything up run:
```bash
git clone https://github.com/brentjens/radio-astronomy-by-notebooks/
```
Do ensure `git-lfs` is installed to fetch the larger files (`sudo apt install git-lfs` on ubuntu-base systems).

Proceed to `cd` into the folder where you just cloned the files into, and run:
```bash
uv run jupyter lab
```
this should start up jupyter in the browser, and allow you to run the `.ipynb` files.

If you do not have `uv` installed, you can find installation instructions at `https://docs.astral.sh/uv/getting-started/installation/`.
